# 9-Dots Research Lab (Анализатор задачи «9 точек»)

Веб-приложение для автоматизированного анализа, калибровки, сегментации и выгрузки статистики решений задачи «9 точек» (Nine Dots Puzzle). Приложение полностью клиентское (работает прямо в браузере, не требует бэкенда и не передает данные на сторонние серверы).

---

## 🌟 Ключевые возможности

1. **Прямой парсинг «сырых» и очищенных данных эксперимента:**
   - Автоматическое определение разделителей (`,` или `;`) и кодировок (`UTF-8`, `Windows-1251`).
   - Автоматический поиск координат 9 точек по коду `isElement === 1`.
   - Автоматическое извлечение метаданных испытуемого из файла:
     - **Имя и Фамилия**: столбцы `surname` / `lastname` / `фамилия` и `name` / `firstname` / `имя` (или единый столбец `name` / `ФИО`). Присутствуют поля быстрого редактирования ФИО прямо в карточке испытуемого.
     - **Пол и Возраст**: распознавание `gender` (`0`/`1`, `женский`/`мужской`, `female`/`male`) и `age`.
     - **Вопросы опросника**: `solvedBefore` (решал ли ранее), `insight` (ощущение озарения).
     - **Шкалы оценки**: автоматический сбор шкал (`Удовольствие`, `Удивление`, `Внезапность`, `Облегчение`, `Уверенность`, `Драйв`, `slider...`).
     - **Общее время**: `totalTaskTime` (учитывается однократно на испытуемого).

2. **Интерактивная калибровка:**
   - 9 точек зафиксированы ровно по центру холста `(400, 400)`.
   - В режиме калибровки мышью или стрелками клавиатуры (`←`, `↑`, `→`, `↓`) перемещается нарисованное решение испытуемого относительно матрицы.
   - Автоматический динамический пересчет попаданий в узлы и классификации линий.

3. **Классификация и сегментация:**
   - Классификация траекторий на типы: `боковая`, `центральная`, `диагональная`, `хордовая`, `хорды_длинные`, `внешняя`, `касательная`, `прочая`.
   - Ручное переопределение типов (Manual Override).
   - Расчет метрик по фазам решения (`Beg`, `Mid`, `End`).

4. **Экспорт данных:**
   - **Filtered Export**: выгрузка отфильтрованных линий с метаданными.
   - **All Data Export**: полная детализированная выгрузка всех проб и линий всех испытуемых.
   - **Summary Statistics**: сводная матричная статистика по каждому испытуемому (со всеми шкалами, фазами, поворотами и типами линий).

## 🚀 Развертывание на GitHub Pages (онлайн-доступ)

Репозиторий уже настроен для мгновенного развертывания через GitHub Actions.

### Шаг 1. Создайте репозиторий на GitHub
1. Перейдите на [github.com/new](https://github.com/new).
2. Укажите имя репозитория (например, `9dots-analysis`).
3. Выберите **Public** (или Private) и нажмите **Create repository** (не добавляйте README, .gitignore или лицензию, они уже есть в проекте).

### Шаг 2. Отправьте код в репозиторий
Откройте терминал в папке проекта и выполните:
```bash
git remote add origin https://github.com/<ВАШ_ЛОГИН>/<ИМЯ_РЕПОЗИТОРИЯ>.git
git branch -M main
git push -u origin main
```

### Шаг 3. Включите GitHub Pages
1. В вашем репозитории на GitHub перейдите в **Settings** (Настройки) -> **Pages**.
2. В разделе **Build and deployment** -> **Source** выберите:
   **GitHub Actions**
3. Перейдите во вкладку **Actions** — вы увидите автоматический запуск процесса `Deploy to GitHub Pages`.
4. Через 1-2 минуты ваш сайт будет доступен по адресу:
   `https://<ВАШ_ЛОГИН>.github.io/<ИМЯ_РЕПОЗИТОРИЯ>/`

## 💻 Локальный запуск и разработка

### Требования
- [Node.js](https://nodejs.org/) (версия 18 или выше)

### Установка и запуск
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/<ВАШ_ЛОГИН>/<ИМЯ_РЕПОЗИТОРИЯ>.git
   cd <ИМЯ_РЕПОЗИТОРИЯ>
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```
   Приложение откроется по адресу `http://localhost:3000`.

4. Для ручной сборки production-версии:
   ```bash
   npm run build
   ```
   Готовые файлы будут в папке `dist/`.
